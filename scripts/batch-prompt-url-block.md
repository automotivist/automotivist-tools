## TOOL LINK RULE — READ FIRST

Add exactly ONE tool link across the entire batch. Choose the single post where a link adds the most value. Skip all others.

### Link selection priority (pick highest match):
1. **Money Guy Post** with a specific payment amount AND salary → use payment/salary page
2. **Cost-shock post** referencing a specific payment amount → use payment page (closest salary match)
3. **Affordability scenario** referencing a specific income/salary → use afford page
4. **Refinancing content** → use refinancing guide
5. **Vehicle-specific content** → use vehicle page
6. **General car finance / ownership cost** → use calculator or guide

### URL patterns:

**Payment/salary analysis** (payment in $50 increments $200-$1500, salary in $10K increments $40K-$200K):
`tools.automotivist.com/car-payment/[PAYMENT]-per-month-[SALARY]-salary`
Example: $650/mo on $75K salary → `tools.automotivist.com/car-payment/650-per-month-75000-salary`
Round to nearest valid increment if exact match unavailable.

**Car affordability by salary:**
`tools.automotivist.com/afford/[SALARY]-salary`
Valid salaries: 40000, 45000, 50000, 55000, 60000, 65000, 70000, 75000, 80000, 90000, 100000, 110000, 120000, 135000, 150000, 175000, 200000
Example: "on a $80K salary" → `tools.automotivist.com/afford/80000-salary`

**Car loan refinancing:**
`tools.automotivist.com/refinance/[OLD]-percent-to-[NEW]-percent`
Example: 10% to 7% → `tools.automotivist.com/refinance/10-percent-to-7-percent`

**Vehicle true cost:**
`tools.automotivist.com/cars/[YEAR]-[MAKE]-[MODEL]`
Example: 2025 Toyota Camry → `tools.automotivist.com/cars/2025-toyota-camry`

**Hub guides:**
- 15% rule guide: `tools.automotivist.com/guides/car-payment-guide`
- True cost guide: `tools.automotivist.com/guides/true-cost-of-ownership`
- Refi guide: `tools.automotivist.com/guides/car-loan-refinancing`

**Calculator (fallback):**
`tools.automotivist.com/calculator`

### Placement rules:
- Add the URL on its own line at the end of the tweet text — never mid-sentence
- The URL counts toward character limit (X shortens all URLs to 23 chars)
- Do NOT add a label like "Link:" or "See:" before the URL — just the URL on its own line
- Do NOT add a link to reply-bait posts, engagement hooks, or posts ending in a question
- Do NOT add a link if the post is already at or near 280 characters before adding the URL
